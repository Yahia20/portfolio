# portfolio-site

My bilingual (Arabic / English) portfolio. Every word and number on the site comes from the
YAML files in `data/`; the build checks them against a schema and turns them into static pages.

## Run it

```bash
pip install -r requirements.txt
python src/build.py --serve        # build + preview on http://localhost:8000
python src/build.py --shots        # also re-render the project images (needs Chrome or Edge)
python -m pytest                   # data and build checks
```

The output in `dist/` is plain HTML/CSS/JS with relative links, so it can be hosted anywhere
(GitHub Pages, Netlify, any static host) or opened straight from disk.

## Where things live

```
data/
  site.yaml             title, navigation labels, contact links
  profile.yaml          about me, services, experience, skills, certifications, photos
  categories.yaml       project categories, in display order
  projects/<slug>.yaml  one file per project — the file name is the URL
  demos/<slug>/         raw output a project page reads (e.g. the call-QA reports)
assets/
  img/profile/          portrait and photos
  projects/<slug>/en|ar images per language (generated by --shots, or your own)
src/
  schema.py             the shape every data file must have
  build.py              validate → render → dist/
  templates/            page layouts; shot.html is the 1200×675 image layouts
  static/               css, js, favicon
```

## Add a project

1. Copy `data/projects/_template.yaml.example` to `data/projects/<slug>.yaml` and fill it in.
   Write for someone who isn't technical; the technical detail goes under `tech`, which the page
   shows collapsed.
2. Pick an existing `category` from `data/categories.yaml`, or add one there.
3. Images: either add shot layouts for it in `src/templates/shot.html` and run
   `python src/build.py --shots`, or drop your own PNGs (1200×675 works best) into
   `assets/projects/<slug>/en/` and `assets/projects/<slug>/ar/`.
4. `python src/build.py --serve` and check both languages.

If anything is missing or misspelled, the build stops and names the file and field, e.g.

```
data\projects\my-project.yaml:
  title → ar: Field required
  stats → 0 → label → with a comma: Extra inputs are not permitted  ← text with a comma inside { en: ..., ar: ... } must be in "double quotes"
```

## Add photos

Put them in `assets/img/profile/`, then in `data/profile.yaml` set `portrait: portrait.jpg`
and add entries under `gallery:`. Until a portrait is set, the site shows initials.

## Publish

Set `base_url` in `data/site.yaml` once the address is known (it enables `sitemap.xml`), build,
and upload the contents of `dist/`.
